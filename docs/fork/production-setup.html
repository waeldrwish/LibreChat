waeldrwish/LibreChat · السيرفر الحالي

تنفيذ الكود على السيرفر

يضيف code-interpreter إلى LibreChat الذي يعمل الآن على السيرفر، فيصبح الوكيل قادراً على إنشاء ملفات Word وExcel وPowerPoint. لا يستبدل LibreChat، ولا يلمس قاعدة البيانات أو الـ reverse proxy.

قيمك

أو اسم السيرفر الذي تستخدمه مع ssh.

عادة root أو ubuntu.

قبل البدء

  • آخر تشغيل لـ Publish Images في مستودع code-interpreter ناجح، والمهام الست خضراء.
  • token من GitHub يقرأ الصور الخاصة. أنشئه من صفحة Tokens (classic) بصلاحية read:packages فقط. السكربت يطلبه منك مرة واحدة.
  • السيرفر يدعم KVM: الأمر ls /dev/kvm يطبع المسار ولا يعطي خطأ. على جهاز عندك، مثل لابتوب، يكفي تفعيل Virtualization من الـ BIOS.
1

انسخ الملفين إلى السيرفر

من جهازك، في PowerShell PS D:\Projects\libre_ai>

ينشئ المجلد /opt/codeapi على السيرفر، منفصلاً عن مجلد LibreChat، وينسخ إليه ملفَّي deploy/codeapi.

copy files

إن كان السيرفر جهازاً عندك، مثل لابتوب لينكس: لا تحتاج IP ولا SSH. انقل الملفين إليه بأي طريقة (فلاشة، Drive، تلغرام)، فلا أسرار فيهما. افتح مجلدهما، واضغط بالزر الأيمن ثم Open in Terminal، ونفّذ:

same machine
sudo mkdir -p /opt/codeapi && sudo cp docker-compose.yml install.sh /opt/codeapi/

ثم في الخطوة 2 تخطَّ سطر ssh.

2

شغّل السكربت

على السيرفر root@server:/opt/codeapi$

يسألك عن token الـ GitHub مرة واحدة، ثم يكمل وحده:

  • يجد حاوية LibreChat وملف .env الخاص بها وحده، ويتوقف دون أي تغيير إن وجد إعدادات تنفيذ كود قديمة.
  • يولّد المفاتيح، ويسحب صور code-interpreter ويشغّلها على شبكة LibreChat، دون فتح أي منفذ.
  • يأخذ نسخة احتياطية من قاعدة البيانات، ثم يضيف بعض الأسطر إلى آخر .env الخاص بـ LibreChat، ويعيد تشغيله مرة واحدة.
  • إن لم يرجع LibreChat خلال ثلاث دقائق، يعيد .env كما كان ويشغّله من جديد.
install
النتيجة المتوقعة: جدول الخدمات، ثم Done. Code execution is connected to LibreChat.

الموقع يتوقف بضع ثوانٍ فقط أثناء إعادة تشغيل LibreChat. شغّله في وقت هادئ.

احفظ نسخة من /opt/codeapi/.env و/opt/codeapi/librechat.env خارج السيرفر. كل منهما يحمل نصف زوج المفاتيح نفسه.
3

فعّله في الوكيل وجرّبه

في المتصفح، على موقعك

افتح إعدادات الوكيل الذي سينشئ الملفات، وفعّل تشغيل الكود (Code Interpreter)، ثم احفظ.

التحديث لإصدار جديد من code-interpreter

خذ SHA آخر تشغيل ناجح لـ Publish Images، بطوله الكامل (40 حرفاً)، ثم على السيرفر:

update code execution
cd /opt/codeapi
grep '^CODEAPI_IMAGE_TAG=' install.sh          # write down the old SHA for rollback
sudo sed -i "s/^CODEAPI_IMAGE_TAG=.*/CODEAPI_IMAGE_TAG=NEW_SHA/" install.sh
sudo bash install.sh

استبدل NEW_SHA قبل التشغيل. التحديث لا يعيد تشغيل LibreChat ولا يغيّر المفاتيح. للتراجع نفّذ نفس الأمرين الأخيرين بالـ SHA القديم. تحديث LibreChat نفسه يبقى كما هو في القسم 3.5 من workflow.md.

أوامر مفيدة

من داخل /opt/codeapi.

إذا حدثت مشكلة

السكربت آمن عند الإعادة: أصلح السبب وشغّله مرة أخرى. لن يغيّر المفاتيح، ولن يضيف الأسطر إلى .env مرتين.

/dev/kvm is missing

السيرفر لا يدعم KVM، فلا يعمل تنفيذ الكود. اطلب من المزوّد تفعيل nested virtualization، أو انقل تنفيذ الكود إلى سيرفر يدعمه.

already sets: LIBRECHAT_CODE_BASEURL …

في .env الخاص بـ LibreChat إعدادات تنفيذ كود سابقة، والرسالة تذكر أسماءها ومسار الملف. ضع # في أول كل سطر منها، ثم شغّل السكربت مرة أخرى.

another code-interpreter is installed

نسخة قديمة من code-interpreter تعمل على السيرفر. ادخل مجلدها وشغّل sudo docker compose down، فتتوقف وتبقى بياناتها، ثم شغّل السكربت مرة أخرى.

the LibreChat image on this server is too old

صورة LibreChat الحالية أقدم من دعم تنفيذ الكود. انشر أحدث وسم من Arabic Admin Panel Image بخطوات القسم 3.5 من workflow.md، ثم شغّل السكربت.

pulling failed مع unauthorized أو denied

الـ token غير صالح أو بلا صلاحية read:packages. سجّل الدخول بـ token جديد، ثم شغّل السكربت مرة أخرى:

ghcr login
sudo docker login ghcr.io -u waeldrwish

إن ظهر not found بدل ذلك، فبناء الصور لم ينتهِ أو فشل. راجع صفحة Publish Images.

إنشاء الملفات لا يعمل

تأكد أن «تشغيل الكود» مفعّل في الوكيل، ثم اقرأ السجلات من الجدول أعلاه. إن ظهر not_yet_valid فساعة السيرفر غير متزامنة، وtimedatectl يجب أن يعرض synchronized: yes.

إن توقف بعد docker compose down ثم up في مجلد LibreChat، فأعد ربطه بالشبكة الجديدة:

reconnect
cd /opt/codeapi && sudo docker compose up -d --force-recreate codeapi
إزالة تنفيذ الكود بالكامل

احذف من .env الخاص بـ LibreChat الأسطر من # >>> code execution حتى # <<< code execution، ثم:

remove
sudo docker restart LibreChat
cd /opt/codeapi && sudo docker compose down

الملفان في deploy/codeapi/ بالمستودع: docker-compose.yml وinstall.sh.
